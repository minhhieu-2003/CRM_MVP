# Code Review Skill

Use this skill when asked to review a diff, PR, or agent-generated patch.

## Review Procedure
1. Identify changed files.
2. Understand intended scope from issue/PR.
3. Compare diff to scope.
4. Check logic, security, type safety, tests, performance, and rollback risk.
5. Return findings by severity.

## Output Format
- Critical
- High
- Medium
- Low
- Suggested follow-up tests
