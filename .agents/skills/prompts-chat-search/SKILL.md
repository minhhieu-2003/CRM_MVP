# prompts.chat Search Command

Use prompts.chat to search for prompt templates or agent skills.

## Usage

```text
/prompts.chat:prompts <query>
/prompts.chat:prompts <query> --category coding
/prompts.chat:prompts <query> --type IMAGE
/prompts.chat:skills <query>
```

## Rule

Discovery only. Do not apply a community prompt to production work until it passes Prompt Review Gate.
