---
name: issue-to-pr
description: Command issue-to-pr
---

Work from GitHub issue $ARGUMENTS to a pull request.

Steps:
1. Read issue and acceptance criteria
2. Create or suggest branch name
3. Plan minimal implementation
4. Wait for approval before editing
5. Implement patch
6. Run tests/build/lint
7. Draft PR body linking issue
8. Include test results and rollback plan

Do not merge the PR.
